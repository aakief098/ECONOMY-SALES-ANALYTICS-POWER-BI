# ECONOMY-SALES-ANALYTICS-POWER-BI
End-to-end Power BI project analyzing $757K in sales for a content creator business. Built 3-page interactive dashboard tracking Revenue by Platform (YouTube, Udemy, etc), Product Category (E-Book, Course, Coaching), Marketing Channel performance &amp; Customer NPS. Features: Custom tooltip pages, Bookmark-based navigation, DAX measures, Slicers &amp; KPI
